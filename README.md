**Проект**

Планировщик задач с веб-интерфейсом. Сервер на Go предоставляет API для добавления, редактирования, удаления, отметки выполнения и просмотра задач. Данные хранятся в SQLite.

---

**Задания со звёздочкой**

Выполнены:
1. Расширенные правила повторения задач `w` и `m`.
2. Поиск задач в `/api/tasks` по подстроке и по дате.
3. Аутентификация через пароль `TODO_PASSWORD` и JWT.
4. Dockerfile для сборки и запуска в контейнере.

---

**Локальный запуск**

Переменные окружения:
1. `TODO_PORT` — порт сервера (по умолчанию `7540`).
2. `TODO_DBFILE` — путь к SQLite базе (по умолчанию `scheduler.db`).
3. `TODO_PASSWORD` — пароль для входа. Если пусто, аутентификация отключена.

Запуск:
1. `go run .`
2. В браузере открыть `http://localhost:7540/`.
3. Если задан `TODO_PASSWORD`, сначала открыть `http://localhost:7540/login.html`, выполнить вход, затем перейти на главную страницу.

---

**Запуск тестов**

1. Обычная проверка: `go test ./tests`.
2. Для расширенных правил повторения в `tests/settings.go` нужно `FullNextDate = true`.
3. Для проверки поиска в `tests/settings.go` нужно `Search = true`.
4. Если задан `TODO_PASSWORD`, нужно получить токен через `/api/signin` и записать его в `Token` в `tests/settings.go`.

---

**Docker**

Сборка образа:
1. `docker build -t scheduler .`

Пример запуска контейнера с БД на хосте:
1. `docker run --rm -p 7540:7540 -v "${PWD}/scheduler.db:/data/scheduler.db" -e TODO_PORT=7540 -e TODO_DBFILE=/data/scheduler.db -e TODO_PASSWORD=12345 scheduler`

После запуска открыть `http://localhost:7540/`.
